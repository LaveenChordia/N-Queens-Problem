 N-Queens Solver

 Overview
This is a simple web-based N-Queens solver that visualizes solutions to the classic N-Queens problem. The user inputs a value of `N` (minimum 4), and the program computes and displays all possible solutions using a backtracking algorithm.

 Features
- Allows users to input a value for `N` (minimum 4).
- Implements a backtracking algorithm to find all valid solutions.
- Displays solutions visually on a dynamic chessboard.
- Responsive and interactive UI with error handling.

 Technologies Used
- HTML for structuring the page.
- CSS for styling and layout.
- JavaScript for logic and DOM manipulation.

 How It Works
1. The user enters a value `N` (>= 4) in the input box.
2. Clicking the Solve button triggers the algorithm.
3. The algorithm recursively places queens on the board while ensuring no two queens attack each other.
4. The valid solutions are displayed on dynamically generated chessboards.

 Installation & Usage
No installation is required! Simply download or clone this repository and open the `index.html` file in any modern web browser.

Alternatively, you can host it on a live server or GitHub Pages for online access.
